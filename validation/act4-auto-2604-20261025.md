# Ubuntu 26.04 ACT4 integration validation

Completed: 2026-10-25T03:44:19.644863+00:00 (UTC).

The version-selectable recipe built a new Ubuntu 26.04 ACT4 image from the
existing Phase 1 `riscv-dev:ubuntu-26.04` image. Spike was compiled from source
inside Ubuntu 26.04. GCC was inherited without rebuilding; its executable SHA-256
matches the Phase 1 base. ACT4, Spike/SoftFloat, Sail and mise pins are unchanged
from the [Ubuntu 24.04 experiment](act4-auto-2404-20261024.md).

## Commands

```bash
# Requires the Phase 1 Ubuntu 26.04 image; build it first if absent.
ACT4_BUILD_NETWORK=host BUILD_JOBS=2 bash scripts/build-act4.sh 26.04
ACT4_OUTPUT=/absolute/empty/output/directory bash scripts/check-act4.sh 26.04
```

Host networking was used with this machine's existing proxy during installation.
Other users can normally omit `ACT4_BUILD_NETWORK=host`. The validation command
always uses `--network none`, including the fresh reference-signature/ELF build.

this failure. The build-task count is not a test count.

Build and validation used two jobs with 4 GiB RAM / 6 GiB including swap. Build
limits were applied using a local legacy-Docker wrapper; the public verification
script supplies its own container limits. Installation used Docker 29.1.3's
legacy builder. Temporary Spike source/object directories were removed before
their image layer finished, and no local proxy environment was stored in the
image. Detailed build logs and generated ELFs remain outside Git.

The 24.04 regression used the retained, previously validated image and the new
host version-selection wrapper; it was not another 24.04 image build. Previous
24.04 validation records remain unchanged.

This verifies the pinned RV64 I suite on Spike across the two Ubuntu baselines.
It does not establish full RVI20U64 coverage, architectural certification,
physical-board behavior, or completion of the separate dev/CI/cert matrix.
Installation requires network access. Ubuntu package repositories and tool
registries are not frozen, so bit-identical rebuilds are not claimed.

# Automated Ubuntu 24.04 ACT4 image validation

Completed: 2026-10-24T15:55:29.944330+00:00 (UTC).

The environment was built using `scripts/build-act4.sh` and `Dockerfile.act4`
from the preserved Phase 1 Ubuntu 24.04 image. It did not import the earlier
manually provisioned ACT4 container. GCC was reused; the separately pinned Spike
was built from source by the recipe. The successful system-tool layer was cached
while finalizing the runtime scripts. This was not a `--no-cache` build.

## Commands and outcome

```bash
PHASE1_IMAGE=riscv-dev-publiccheck:phase1-ubuntu-24.04-20261024 \
  ACT4_BUILD_NETWORK=host BUILD_JOBS=2 bash scripts/build-act4.sh
ACT4_OUTPUT=/absolute/empty/output/directory bash scripts/check-act4.sh
```

The named base is this machine's preserved Phase 1 public-recheck image. Other
users normally build `riscv-dev:ubuntu-24.04` using the Phase 1 instructions, then
use the default ACT4 commands in [ACT4.md](../ACT4.md).

this expected failure. The 204 build tasks are not 204 tests.

machine-specific proxy was stored in the resulting image. Temporary Spike
source/object directories were absent after installation. The final build
transcript and test artifacts were retained outside Git; only the selected evidence above
is committed.

## Limits

This verifies the selected RV64 I suite on Spike, not the entire RVI20U64 profile,
physical hardware, architectural certification, Ubuntu 26.04, or separate
dev/CI/cert images. Installation requires network access; offline validation
uses dependencies prepared during the image build. Ubuntu package repositories
and tool-manager registries are not frozen, so bit-identical rebuilds are not
claimed. The earlier [manual integration record](act4-2404-20261024.md) remains
separate evidence.
